⚙️ إعداد أولي مطلوب

لم يتم بعد ربط هذا الملف بمشروع Supabase الخاص بك.

افتح هذا الملف بمحرر نصوص (مثل Notepad)، ابحث عن الكلمة APP_CONFIG قرب نهاية الملف، وعدّل القيمتين:

window.APP_CONFIG = {
  SUPABASE_URL: "https://xxxxxxxx.supabase.co",
  SUPABASE_ANON_KEY: "eyJhbGciOi...",
};

تجدهما في لوحة مشروعك على supabase.com ← Project Settings ← API (Project URL و anon public key). ثم احفظ الملف وأعد فتحه.
